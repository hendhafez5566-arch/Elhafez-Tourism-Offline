# Generated Artifact Policy

**Scope:** FINAL HARDENING (checkpoint safeguards only). Documentation-only policy.
No generated directory is modified, regenerated, deleted, or untracked in this stage.

This document records the **verified current state** of generated artifacts in the repository.

---

## 1. `dist/` (Client build output)

- **Nature:** Generated (client/offline build output).
- **Tracking status:** Currently tracked in Git.
- **Regeneration:** Regenerated by the client/offline build (`npm run build` pipeline).
- **Policy:** NOT untracked in this phase. Left as-is until an explicit future batch decides otherwise.

## 2. `server/dist/` (Server TypeScript build output)

- **Nature:** Generated (server TypeScript compilation output).
- **Tracking status:** Currently tracked in Git.
- **Dependency:** Server runtime / packaging flow depends on it.
- **Policy:** NOT untracked in this phase. Left as-is until an explicit future batch decides otherwise.

## 3. `android/app/src/main/assets/public/` (Android synced web assets)

- **Nature:** Generated/synced output (offline copy of client build for Android packaging).
- **Tracking status:** Currently tracked in Git.
- **Dependency:** Android packaging and parity checks depend on it.
- **Policy:** NOT untracked in this phase. Left as-is until an explicit future batch decides otherwise.

---

## Rules For This Stage

1. **Documentation only.** No generated directory content changes are allowed here.
2. `node_modules/` and `server/node_modules/` MUST NOT be tracked (enforced by `.gitignore`, verified via `git ls-files 'node_modules/**'` returning zero results).
3. Any future untracking of `dist/`, `server/dist/`, or `android/app/src/main/assets/public/` requires a dedicated batch with its own verification gate — it is explicitly out of scope for the hardening checkpoint.
